About Medi AI

Understanding the purpose and design of the Medi AI system

Medi AI is an intelligent disease prediction system designed to assist users in identifying possible common illnesses based on selected symptoms. The system leverages machine learning techniques to provide probability-based insights in a simple and user-friendly interface.

How It Works

  • Users select the symptoms they are experiencing
  • The system analyzes inputs using a trained ML model
  • Top probable diseases are predicted with confidence scores
  • Predictions can be referenced through the application

Technology Stack

  • Python & Flask for backend services
  • Machine learning model for disease prediction
  • CSV-based structured datasets
  • Tailwind CSS for responsive UI design

Medical Disclaimer

Medi AI is intended for educational and informational purposes only. It does not provide medical diagnosis or treatment. Always consult a qualified healthcare professional for medical advice.
